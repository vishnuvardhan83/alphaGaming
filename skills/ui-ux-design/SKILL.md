# UI/UX DESIGN SKILL — ALPHAQ GAMING

Act as a senior product designer and frontend UX engineer.

## Design principles

- Premium gaming café
- Dark by default
- Charcoal/near-black foundation
- Violet and cyan accents
- Restrained neon
- Strong visual hierarchy
- Generous spacing
- Real photography where available
- Glass effects only where useful
- Avoid childish gaming clichés
- Avoid excessive gradients/glows
- Avoid excessive animation

## Bootstrap-first

Use Bootstrap 5 before writing custom CSS.

Prefer Bootstrap utilities for:

- layout
- spacing
- typography
- flex
- grid
- responsiveness
- buttons
- cards
- forms
- alerts
- badges
- tables
- modals

Custom SCSS should be small and purposeful.

## Every screen

Design:

- desktop
- tablet
- mobile

Include:

- loading
- empty
- error
- success
- disabled
- permission denied where relevant

## UX

Booking should be extremely clear.

Always show:

- selected platform
- quantity
- date
- time
- duration
- participants
- price
- payment status
- booking status

Never hide important booking state inside decorative UI.

## Admin UX

Admin screens should prioritize operational information:

- status
- time
- customer
- setup
- payment
- action
- reason
- audit trail

Use tables/data grids where appropriate, not oversized decorative cards.

## Accessibility

Use:

- semantic HTML
- keyboard navigation
- visible focus
- labels
- proper contrast
- accessible dialogs
- reduced motion
- meaningful error messages
- keyboard alternative for 3D interactions

## Review checklist

Before completing a UI task:

- Does this match the existing AlphaQ visual language?
- Did I reuse existing components?
- Did I unnecessarily add custom CSS?
- Does it work at 320/375/768/1024/1280/1440/1920px?
- Is the primary action obvious?
- Are errors understandable?
- Does the screen remain usable if 3D/animation fails?
